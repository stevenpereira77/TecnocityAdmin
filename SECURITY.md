# Seguridad

No publiques vulnerabilidades explotables, credenciales, tokens OAuth, bases de datos reales ni datos personales en incidencias públicas.

Para reportar un problema de seguridad, utiliza la opción **Private vulnerability reporting** de GitHub si está habilitada en el repositorio. Si no está disponible, contacta al titular del repositorio por un canal privado que este haya publicado. No se incluye una dirección de correo en este archivo para evitar inventar un contacto.

Al compartir registros para reproducir un error, elimina nombres, correos, teléfonos, rutas de usuario, identificadores de Google, tokens, datos de clientes y cualquier información comercial privada.

## Recomendaciones para usuarios

- Descarga el proyecto únicamente desde el repositorio oficial.
- Instala dependencias desde `requirements.txt` y evita ejecutar scripts desconocidos.
- Mantén `client_secret.json` y `token.json` fuera del control de versiones.
- Protege las copias de seguridad locales y de Google Drive.
- Usa una copia de prueba antes de actualizar una base de datos importante.
